📦 Cómo instalar skills en cualquier agente

1. Instala el CLI de skills

Necesitas Node.js. El CLI se ejecuta con npx, sin instalación global.

npx skills add <repo> --skill <nombre>

2. Elige el skill y ejecútalo

Cada skill tiene su propio comando de instalación. Cópialo y ejecútalo en la raíz de tu proyecto. El CLI descarga el SKILL.md y los recursos asociados en la carpeta .skills/ de tu proyecto.

3. Funciona con cualquier agente compatible

Claude Code, Cursor, Windsurf, Copilot, OpenCode, Codex… Cualquier agente que lea archivos SKILL.md puede usar las skills instaladas automáticamente.

4. Gestiona tus skills

Consulta las skills instaladas, actualiza o elimina las que ya no necesitas.

npx skills list  ·  npx skills update  ·  npx skills remove <nombre>
